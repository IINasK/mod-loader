# Nissan GTR R35

- ID: `mod-11659`
- Versao fixa: V1.2; jogo 2.5.
- Grupo: Veiculos.
- Phantom Liberty: not-required.
- Situacao: Disponivel conforme perfil e requisitos.

## Funcao

Adiciona Nissan GTR R35 como veículo independente, com modelo/entidade e ajustes próprios; não é simples substituição do carro original.

## Como usar

- Comprar via Virtual Car Dealer quando suportado; alternativa oficial é habilitar o veículo pelo console CET com o ID específico. Depois chamar pela lista de veículos do jogo.

Comando publicado pelo autor:

```lua
Game.GetVehicleSystem():EnablePlayerVehicle("Vehicle.2017_nissan_gtr_r35_default", true, false)
```
