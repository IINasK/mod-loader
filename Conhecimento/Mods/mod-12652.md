# Toyota Supra Mk5 HKS Widebody

- ID: `mod-12652`
- Versao fixa: 1.0.5-Minor; jogo 2.5.
- Grupo: Veiculos.
- Phantom Liberty: not-required.
- Situacao: Disponivel conforme perfil e requisitos.

## Funcao

Adiciona Toyota Supra Mk5 HKS Widebody como veículo independente, com modelo/entidade e ajustes próprios; não é simples substituição do carro original.

## Como usar

- Comprar via Virtual Car Dealer quando suportado; alternativa oficial é habilitar o veículo pelo console CET com o ID específico. Depois chamar pela lista de veículos do jogo.

Comando publicado pelo autor:

```lua
Game.GetVehicleSystem():EnablePlayerVehicle("Vehicle.supra_hks_widebody_01", true, false)
```
