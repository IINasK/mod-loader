# NETGVNNER - FL00R SHXT POSE PACK

- ID: `mod-35353`
- Versão conferida: 1, arquivo Nexus 168808.
- Situação: retirado do catálogo Dev em 10/11/2026 após crash comprovado no NightCoop 0.2.0 ao processar um nome de pose UTF-8. As assinaturas foram preservadas para reconhecer instalações antigas.

## Função

Pacote de 36 poses femininas de chão para o modo foto. O YAML contém 56 registros únicos:36 poses-base e20 variações, incluindo opções para corpos específicos.

## Como usar

- Abrir o modo foto > poses > categoria NETGVNNER - FL00R SHXT.
- As poses foram pensadas para sapatos de plataforma; salto fino ou solado baixo pode alterar o contato com o chão.
- Para as poses armadas aparecerem, o autor pede uma pistola no inventário.
- Mantendo o corpo padrão, começar pelas variações sem marcação ANGEL/EBB; os nomes das variações não obrigam a instalar esses corpos.
