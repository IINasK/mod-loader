# Vehicle Speed Unlimiter

Versão 1.0.2. Remove o limite geral de velocidade dos veículos e exige RED4ext.

O Windows registrou duas falhas ao iniciar o Cyberpunk 2.5 enquanto o RED4ext carregava este plugin. O jogo voltou a abrir após sua desativação. O Mod Loader 1.0.35 bloqueia a instalação e mantém os dados necessários para ler os recibos anteriores.
