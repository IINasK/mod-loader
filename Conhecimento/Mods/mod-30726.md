# Redscript Configuration Framework

Versão 3.2.2 para Cyberpunk 2077 2.5. Fornece os menus de configuração em jogo usados pelo WEAVE. É instalado como dependência; as configurações pessoais ficam no jogo.

Requer redscript, Codeware, Input Loader, RED4ext e RedFunctions 0.14.2 ou superior. Mod Settings, RedLogger e RedIMGRetriever são opcionais. Nenhum requisito de Phantom Liberty ou REDmod indicado pelo autor. O pacote mantém a versão atual de RED4ext.
