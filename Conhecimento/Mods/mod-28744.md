# Vehicle Manufacturer Fix

- ID: `mod-28744`
- Versao fixa: 1.0; jogo 2.5.
- Grupo: Veiculos.
- Phantom Liberty: not-required.

## Funcao

Corrige a apresentação do fabricante no scanner para veículos com fabricantes personalizados.

## Como usar

- Sem configuração ou loja própria. Escaneie um veículo suportado para exibir o fabricante correspondente.
