# Better Loot Markers

- ID: mod-3486; versão 1.4.1; Nexus file_id171665, publicado em31/10/2026.
- Autor declara suporte ao Cyberpunk2.5. Compatível documentalmente com nosso CET1.38.1; instalado localmente em02/11/2026. Leitura visual no jogo ainda não realizada nesta instalação.

## Função e uso

Exibe ícones por categoria de loot e usa cores para indicar a maior qualidade de cada categoria. Não entrega itens nem muda o corpo. Carrega automaticamente com CET; não exige comando de console ou tecla própria.

Abra o overlay pela tecla que você definiu para CET. No painel BetterLootMarkers:

- Vertical Mode: disposição vertical.
- Show Default Markers: mantém também os marcadores originais.
- Marker Scaling: escala0..1.
- Immersive Mode (Scanner Only): mostra loot somente durante scanner.
- Show Item Counts: quantidade por categoria.

Padrões do arquivo: vertical=false, defaultMarkers=false, scale1, itemCounts=false, immersive=false. Alterações são gravadas ao fechar o overlay quando houver edição, e também no encerramento do mod. Configuração gerada: bin/x64/plugins/cyber_engine_tweaks/mods/BetterLootMarkers/config.json. Esse arquivo não vem no ZIP nem é removido pela receita.

## Dependências e compatibilidade

Página atual exige CET>=1.38.1, já instalado. README interno cita1.34.1+, divergência antiga; esta receita segue o requisito atual mais alto, sem atualizar nada. Não requer RED4ext adicional, Native Settings, REDmod, ArchiveXL ou TweakXL. Os arquivos são Lua, README e version.txt.

Sem requisitos de corpo/gênero/DLC e sem referências EP1 nos scripts examinados. Classificação semDLC inferida pelo escopo do HUD base, não por teste separado sem Phantom Liberty. Não modifica câmera ITP, controles, rates ou física FPV.

Usa ObserveAfter em GameplayMappinController.UpdateVisibility/UpdateIcon, observação do scanner e reparo de visibilidade após sair do scanner. Outro mod que altere os mesmos widgets/visibilidade pode interagir. Busca inicial nos CET instalados não encontrou outro BetterLootMarkers ou override direto desses mesmos métodos; isso não exclui interações em DLLs/redscript. O NCPD Hotline possui código de interação de HUD, mas presença do termo mappin não demonstra conflito.

Coop: lê informações de loot do cliente e desenha HUD local, sem API de rede identificada. Não sincroniza loot nem prova equivalência de inventários entre jogadores. Funcionamento desta adição deve ser observado no jogo; não reclassifica as validações anteriores do usuário.
