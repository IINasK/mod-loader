# Pagani Zonda Cinque Roadster

- ID: `mod-8795`
- Versao fixa: 1.4; jogo 2.5.
- Grupo: Veiculos.
- Phantom Liberty: not-required.
- Situacao: Disponivel conforme perfil e requisitos.

## Funcao

Adiciona Pagani Zonda Cinque Roadster como veículo independente, com modelo/entidade e ajustes próprios; não é simples substituição do carro original.

## Como usar

- Comprar via Virtual Car Dealer quando suportado; alternativa oficial é habilitar o veículo pelo console CET com o ID específico. Depois chamar pela lista de veículos do jogo.

Comando publicado pelo autor:

```lua
Game.GetVehicleSystem():EnablePlayerVehicle("Vehicle.pagani_zonda_cinque_01", true, false)
```
