# Audi R8 Liberty Walk

- ID: `mod-8827`
- Versao fixa: 1.4 declarada; nome ZIP 1.3; jogo 2.5.
- Grupo: Veiculos.
- Phantom Liberty: not-required.
- Situacao: Disponivel conforme perfil e requisitos.

## Funcao

Adiciona Audi R8 Liberty Walk como veículo independente, com modelo/entidade e ajustes próprios; não é simples substituição do carro original.

## Como usar

- Comprar via Virtual Car Dealer quando suportado; alternativa oficial é habilitar o veículo pelo console CET com o ID específico. Depois chamar pela lista de veículos do jogo.

Comando publicado pelo autor:

```lua
Game.GetVehicleSystem():EnablePlayerVehicle("Vehicle.audi_r8_lbw_01", true, false)
```
