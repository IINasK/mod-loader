# Nissan 240SX S13

- ID: `mod-8730`
- Versao fixa: 1.32; jogo 2.5.
- Grupo: Veiculos.
- Phantom Liberty: not-required.
- Situacao: Disponivel conforme perfil e requisitos.

## Funcao

Adiciona Nissan 240SX S13 como veículo independente, com modelo/entidade e ajustes próprios; não é simples substituição do carro original.

## Como usar

- Comprar via Virtual Car Dealer quando suportado; alternativa oficial é habilitar o veículo pelo console CET com o ID específico. Depois chamar pela lista de veículos do jogo.

Comando publicado pelo autor:

```lua
Game.GetVehicleSystem():EnablePlayerVehicle("Vehicle.nissan_240sx", true, false)
```
